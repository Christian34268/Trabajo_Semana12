# Cómo ejecutar

1. Instala el SDK de .NET 8 (en Fedora: `sudo dnf install dotnet-sdk-8.0`).
2. Entra a la carpeta del proyecto: `cd BibliotecaApp`
3. Ejecuta: `dotnet run`

Se abrirá un menú en consola. La opción **8** corre la comparación de tiempos
de ejecución (List vs Dictionary vs HashSet) que necesitas para el análisis
de la guía.

Toma una captura de pantalla del menú y de la opción 8 para el anexo del informe.
